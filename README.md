# 🔢 Myra's Number Blocks

A colorful, animated educational app for learning multiplication with big numbers! Designed specifically for 5-year-olds to understand how multiplying 10×100=1000 and other large number concepts in a fun, interactive way.

## Features

✨ **Colorful Animations**: Bright, eye-catching colors and smooth animations keep kids engaged

🎮 **Interactive Learning**: Click answers to test understanding, with immediate feedback

🎨 **Visual Learning**: See the blocks multiply before your eyes! Toggle visual representations to understand multiplication concepts

🎯 **Progressive Difficulty**: 11 levels starting from 10×10 up to huge numbers like 10,000×100

🎵 **Sound Effects**: Fun audio feedback for correct/incorrect answers and level-ups

🏆 **Score Tracking**: Earn points and level up as you master each concept

💾 **Progress Saving**: Your level and score are automatically saved

📱 **Mobile-Friendly**: Works great on phones, tablets, and computers

## How to Play

1. **Look at the Problem**: See the multiplication problem at the top (e.g., 10 × 100 = ?)

2. **Choose Your Answer**: Tap one of the four colorful answer buttons

3. **Get Feedback**:
   - ✅ Correct? You'll see celebration confetti and hear happy sounds!
   - ❌ Wrong? Try again! The app lets you retry

4. **See the Magic**: Press "See the Magic!" to watch animated blocks show how the multiplication works

5. **Level Up**: Answer correctly to earn points and unlock bigger numbers!

## Learning Concepts

This app teaches:
- **Place Value**: Understanding tens, hundreds, thousands
- **Multiplication Patterns**: Seeing how multiplying by 10, 100, 1000 adds zeros
- **Visual Grouping**: Understanding multiplication as "groups of" numbers
- **Number Sense**: Building comfort with large numbers

## Technical Details

- **Pure HTML/CSS/JavaScript**: No dependencies, runs entirely in the browser
- **Local Storage**: Progress is saved automatically
- **Web Audio API**: Simple sound effects for engagement
- **Responsive Design**: Works on any screen size
- **Accessibility**: High contrast, large touch targets (44px+), keyboard accessible

## Deployment to GitHub Pages

1. Create a new GitHub repository named `myra-number-blocks`

2. Push these files to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Myra's Number Blocks app"
   git remote add origin https://github.com/YOUR-USERNAME/myra-number-blocks.git
   git push -u origin main
   ```

3. The included `.github/workflows/deploy.yml` will automatically deploy to GitHub Pages

4. Access the app at: `https://YOUR-USERNAME.github.io/myra-number-blocks/`
